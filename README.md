# Laboratorio de Robótica Móvil: Modelado, Control y Navegación en ROS 2

Repositorio oficial que recopila el desarrollo práctico e informes de laboratorio sobre modelado cinemático, control en lazo cerrado, SLAM y navegación autónoma de robots móviles utilizando Python, ROS 2 (Jazzy) y Gazebo.

## 🚀 Contenido del Repositorio
- Cinemática y control (Guía 4): Implementación de modelos tipo bicicleta y tracción diferencial (`go_to_goal`, evasión reactiva y seguimiento de trayectorias Pure Pursuit).
- Mapeo y localización (SLAM): Construcción de mapas de ocupación mediante Cartographer con el robot TurtleBot3 Burger.
- Navegación autónoma (Nav2): Configuración de mapas de costo, servidores globales/locales, AMCL y gestión de acciones autónomas.
- Informes técnicos: Documentación formal redactada en \LaTeX\ (\textit{Overleaf}) con análisis de resultados y evidencias experimentales.
